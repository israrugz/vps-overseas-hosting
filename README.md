## 免备案VPS适合哪些场景？

海外 VPS 常见于面向海外访客的网站、跨境业务、开发测试环境，以及希望先部署再逐步调整的项目。若服务器不在中国大陆，通常可以省去大陆服务器接入网站所涉及的 ICP 备案流程；但这不等于所有业务都自动合规，也不代表从中国大陆访问一定快。

先看访客在哪，比先看 CPU 型号更有用：

- **访客主要在海外**：优先考虑离主要用户较近的数据中心。例如面向北美用户的网站，通常应先比较北美节点的实际延迟和网络表现。
- **访客主要在中国大陆**：需要关注跨境线路、运营商和高峰时段的丢包情况。普通国际线路与面向中国方向优化的线路，价格和体验可能不同。
- **只是测试或开发**：先确认系统、远程管理方式和预算。短期测试不一定需要高配套餐，过度购买只会让闲置资源按月收费。

“免备案”解决的是上线前的一项流程问题，并不替你解决访问速度、域名配置、系统维护和数据备份。选购时把这些事情分开判断，比较不容易被一个标签带偏。

## 选购前先看位置、线路和资源

### 机房位置要匹配访客

服务器离用户较远时，网络往返时间通常更长。即使套餐标注了较高的端口速率，也不能单凭这个数字判断网站打开得快不快：端口速率代表链路能力的一部分，不等于某个访客到服务器的端到端速度。

BandwagonHost 官网当前介绍多个机房，并在 CN2 GIA 页面说明其洛杉矶相关服务提供面向中国方向的网络选项。该页面也提到香港和日本的相关服务价格会更高。具体能买到哪些地点、地点对应的库存和套餐，应以结账页面显示为准；不要把“多地点可选”理解成每档套餐随时都有所有机房。

### 线路名称不是速度保证

BandwagonHost 的网络说明把 CN2 GIA/CTGNet 定位为面向中国方向的网络方案，并说明相关线路成本和容量限制。它适合被当作选购时要核实的线路信息，不应被理解成任何地区、运营商、时段都必然低延迟或零丢包。实际体验会受本地运营商、路由、机房和时段影响。

购买前可以先问自己：目标用户是否在中国大陆？是否有跨境访问体验要求？如果有，除了产品页面的线路描述，还应查看近期网络测试或先用小额方案验证。服务商的线路说明是重要参考，但不是你所在网络环境的实时测速结果。

### CPU、内存、存储和流量要一起看

网站类型决定资源优先级。静态页面、轻量个人站和开发环境，通常不需要一开始就选择大内存方案；数据库、多个站点或持续运行的应用，则要预留内存和磁盘空间。流量额度也要纳入预算：媒体文件下载、图片较多的页面和频繁的数据传输，消耗会比纯文字站点更快。

官网套餐使用 RAID-10 SSD 容量标注，RAM、CPU 和每月流量随档位增加。页面写明 CPU 数量，但没有在该价格列表中给出每个套餐可独占的物理核心性能保证，因此不宜把 CPU 数量直接等同于固定性能承诺。
